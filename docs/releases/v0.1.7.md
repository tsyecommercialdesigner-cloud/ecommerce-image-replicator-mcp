# v0.1.7 — 画布尺寸补偿、本地后处理恢复与代理兼容

候选版本，尚未发布。最终目标、CI及附件摘要以正式发布核验结果为准；不覆盖已有标签或附件。

- PNG/JPEG输出与请求画布宽高比偏差不超过1%时，归一化请求画布、裁去补边并恢复原参考图精确宽高。明显偏差明确报错并保留raw，不改变模型路由。
- 新增recover_postprocess，共12工具/1资源/1提示；使用原run_id和指定image_ids，本地恢复downloaded的v2图片。保留receipt、raw、原输入和其他成功图，不调用分析、绘图、下载或付费验收。结果需视觉验收，不能把raw直接作为成品。
- 默认保留代理，在客户端兼容NO_PROXY合法方括号IPv6及端口规则，不改os.environ/Host/用户配置。新增--proxy-mode direct，显式忽略代理而保留CA环境及TLS校验；非法配置不自动降级直连。
- 本地256通过/1项平台跳过，包含保留7图、并发/重启、结构化错误、两模型自动补偿和代理路由。实际DSH Desktop 0.2.1-rc.2宿主派生诊断子进程：旧v0.1.6初始化失败，修复源码environment/direct初始化通过，无供应商请求；该验证不代表完整收费业务验收。

安装/升级保留.env、工作区、索引、原任务和成功产物，默认无需新增Host参数。新本地恢复标记不受旧版本识别；建立新恢复后不混用新旧版本执行同一工作区。回滚保留验证仅针对升级前旧任务，不能据此承诺新任务可降级执行。
