# v0.1.1

修复Windows提升权限创建运行目录后普通Host无法访问的问题。新`.replicator`继承业务工作区ACL，POSIX继续0700；已有ACL不自动改写。启动权限不足或数据库初始化失败时输出清晰stderr诊断并非零退出，保留任务数据库。

默认业务工作区统一为`D:\EcommerceImageReplicator`，JSON模板、Codex TOML和安装/检查/启动命令一致。推荐同一账号普通PowerShell安装与启动。现有用户可以继续显式使用原工作区；不自动迁移数据。
