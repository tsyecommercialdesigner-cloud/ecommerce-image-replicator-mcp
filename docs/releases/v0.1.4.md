# v0.1.4 — Windows并发路径包含检查修复

发布候选，尚未公开。通过PR、Windows/Linux CI与合入复验后，标签CD先生成草稿，附件摘要与隔离安装验证完成后公开。

修复Python Windows非严格路径解析在目录创建竞争中保留扩展前缀，导致同一工作区被误判越界的问题。
统一DOS/UNC比较表示，保持返回路径的root表示和原任务绑定，保留真实越界、链接、设备路径及权限校验。
稳定复现、修复边界与23项定向回归见[根因记录](../WINDOWS-PATH-FIX.md)。
沿用v0.1.3默认不限额策略。保留.env及ACL、业务目录、任务索引、receipt、checkpoint和产物；无收费API调用，不修改成员真实Host配置。
已有发布标签和附件不覆盖。实际目标SHA、CI、下载摘要、安装与升级保留结果待核验后回填。
